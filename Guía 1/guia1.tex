	\section{Resumen de la materia (hasta ahora)}
	\subsection{Comentarios en el código}
	Los comentarios son anotaciones que dejamos en nuestro código para explicar qué hace cierta parte del programa. El computador ignora estos textos por completo al momento de ejecutar el código, por lo que existen exclusivamente para ayudarnos a nosotros (o a quien revisa) a entender qué estábamos pensando al programar. 
	
	En Python, los comentarios de una sola línea se escriben anteponiendo el símbolo de ``gato'' o \textit{hash} (\texttt{\#}).
	
	\begin{lstlisting}
		# Este es un comentario, el programa lo ignorará por completo
		temperatura = 45  # También podemos escribir comentarios al lado del código
	\end{lstlisting}
	
	\subsection{Variables y tipos de datos}
	Las variables son como ``cajas'' o contenedores en la memoria de nuestro computador donde podemos guardar información. Cada variable tiene un nombre único que nos permite identificarla y acceder a su valor o modificarlo más adelante en la ejecución del programa.
	
	Los cincos tipos de datos que usaremos principalmente son los siguientes:
	\begin{enumerate}
		\item \textbf{Enteros} (int): Son todos los números que van desde el $-\infty$ hasta el $\infty$ \textbf{sin contar decimales}. Por ejemplo: \texttt{42}, \texttt{67}, \texttt{-341}.
		
		\item \textbf{Flotantes} (float): Representan a los números reales, es decir, \textbf{aquellos que tienen decimales}. En Python, los decimales se separan con un punto (\texttt{.}) y no con una coma. Por ejemplo: \texttt{3.14}, \texttt{-0.5}, \texttt{2.0}.
		
		\item \textbf{Cadenas de texto} (str): Conocidas como \textit{strings}, se utilizan para almacenar texto (letras, palabras, oraciones o símbolos). Siempre deben estar encerradas entre comillas simples (\texttt{'Hola'}) o dobles (\texttt{"Hola"}).
		
		\item \textbf{Booleanos} (bool): Son variables lógicas que solo pueden tomar dos valores: \texttt{True} (Verdadero) o \texttt{False} (Falso). Son fundamentales para tomar decisiones lógicas en nuestro código.
		
		\item \textbf{Listas} (list): Son estructuras que nos permiten agrupar múltiples datos (incluso de distinto tipo) de forma ordenada en una sola variable. Se definen utilizando corchetes \texttt{[]}. Por ejemplo: \texttt{[1, 2, 3]} o \texttt{['manzana', 'pera']}.
	\end{enumerate}
	
	\subsection{Declaración y redefinición de variables}
	Para \textbf{declarar} (crear) una variable, simplemente inventamos un nombre representativo y le asignamos un valor usando el signo igual (\texttt{=}). \\ 
	
	Ojo! En programación, el signo \texttt{=} significa \textbf{asignación}, no igualdad matemática. El nombre de la variable siempre va a la izquierda y el valor que queremos guardar a la derecha.\\
	
	Es de vital importancia entender que \textbf{las variables pueden cambiar de valor} a medida que el programa avanza. A esto le llamamos \textbf{redefinir} o actualizar una variable. Podemos sobreescribir el valor con uno nuevo, e incluso usar el valor antiguo para calcular el nuevo:
	
	\begin{lstlisting}
		# Declaración inicial
		juegos_steam = 4
		saldo_billetera = 15000
		
		# Redefinición directa
		# Reemplazamos el valor viejo con uno completamente nuevo
		saldo_billetera = 10500  
		
		# Redefinición usando su propio valor (Actualización)
		# Si compramos un juego más, tomamos el valor actual (4), le sumamos 1, 
		# y guardamos el nuevo resultado (5) en la misma variable.
		juegos_steam = juegos_steam + 1
	\end{lstlisting}
	
	\subsection{Operadores Matemáticos}
	Para hacer cálculos en Python, utilizamos símbolos especiales llamados operadores. Además de los clásicos ya conocidos, la programación introduce un par de operadores nuevos que serán increíblemente útiles durante el semestre:
	
	\begin{itemize}
		\item \textbf{Suma (\texttt{+})} y \textbf{Resta (\texttt{-})}: Funcionan de manera tradicional.
		
		\item \textbf{Multiplicación (\texttt{*})}: Se utiliza el asterisco en lugar de una ``x''.
		
		\item \textbf{División normal (\texttt{/})}: Realiza la división matemática exacta. \textbf{Siempre retorna un \texttt{float} (decimal)}, incluso si la división es perfecta. Por ejemplo, \texttt{10 / 2} resulta en \texttt{5.0}.
		
		\item \textbf{División entera (\texttt{//})}: Realiza la división pero \textbf{descarta completamente los decimales}, entregando solo la parte entera. Por ejemplo, \texttt{5 // 2} resulta en \texttt{2}. Ojo, no redondea, simplemente corta lo que está después del punto!
		
		\item \textbf{Módulo o Resto (\texttt{\%})}: Este operador entrega el \textbf{sobrante} de una división entera. Por ejemplo, si tenemos 5 manzanas y las dividimos entre 2 personas, cada uno recibe 2 y sobra 1. Por lo tanto, \texttt{5 \% 2} resulta en \texttt{1}. Es fundamental, por ejemplo, para saber si un número es par o impar.
		
		\item \textbf{Exponenciación (\texttt{**})}: Sirve para elevar una base a un exponente. Por ejemplo, \texttt{2 ** 3} equivale a $2^3$, dando como resultado \texttt{8}.
	\end{itemize}
	
	\newpage
	
	\begin{lstlisting}
		# Ejemplos de uso
		saldo = 15000
		precio_juego = 4000
		
		# Cuantos juegos puedo comprar sin quedar debiendo? (División entera)
		juegos_comprables = saldo // precio_juego  # Resultado: 3
		
		# Cuánto dinero me sobraria tras comprar esos 3 juegos? (Módulo)
		vuelto = saldo % precio_juego  # Resultado: 3000
		
		# Calculando componentes
		memoria_ram = 2 ** 4  # Resultado: 16
	\end{lstlisting}
	
	\subsubsection*{Orden de precedencia y uso de paréntesis}
	Al igual que en las matemáticas tradicionales, Python respeta un orden de operaciones estricto. Primero se resuelven los paréntesis, luego las potencias, seguido de las multiplicaciones y divisiones (incluyendo división entera y módulo) de izquierda a derecha, y finalmente las sumas y restas.
	
	Si necesitas alterar este orden o simplemente quieres que tu cálculo sea más seguro y fácil de leer, \textbf{debes usar paréntesis curvos \texttt{()}}. Ojo! En Python matemático no se usan corchetes \texttt{[]} ni llaves \texttt{\{\}} para agrupar operaciones, solo paréntesis curvos, sin importar cuántos necesites anidar.
	
	\begin{lstlisting}
		# Ejemplo de precedencia
		# Primero multiplica (5*2), luego suma 10. Resultado: 20
		resultado1 = 10 + 5 * 2   
		
		# Primero resuelve el paréntesis (10+5), luego multiplica. Resultado: 30
		resultado2 = (10 + 5) * 2 
		
		# Uso de multiples paréntesis para asegurar el orden
		calculo_complejo = ((3 + 4) * 2) ** 2
	\end{lstlisting}
	
	\subsection{Entrada y salida}
	Para que nuestro programa sea interactivo, necesita comunicarse con el usuario. Para esto utilizamos dos funciones fundamentales:
	
	\begin{itemize}
		\item \textbf{Salida (\texttt{print()})} : Muestra información en la pantalla. Podemos imprimir texto, el valor de una variable, o varias cosas a la vez separándolas por comas.
		
		\item \textbf{Entrada (\texttt{input()})}: Pausa el programa y espera a que el usuario escriba algo por el teclado y presione \textit{Enter}. Lo que el usuario escriba será guardado en una variable.
	\end{itemize}
	
	\begin{lstlisting}
		# Salida de datos
		nombre = "Karina"
		edad = 21
		# Imprimiendo texto y variables juntas
		print("Hola", nombre, "tienes", edad, "años.")
		
		# Entrada de datos
		# El programa se detiene a esperar que el usuario escriba
		comida = input("Ingresa tu comida favorita: ")
		print("Tu comida favorita es:", comida)
	\end{lstlisting}

	\subsection{Casteo (conversión)}
	El \textbf{casteo} (o conversión) es la acción de transformar un tipo de dato en otro compatible utilizando las funciones nativas de Python: \texttt{int()}, \texttt{float()}, \texttt{str()} y \texttt{bool()}.
	
	En programación, a menudo nos encontraremos con situaciones donde un dato no está en el formato que necesitamos. Por ejemplo, intentar realizar cálculos matemáticos con texto, o querer unir un número a una oración sin que Python nos arroje un error. Aquí es donde entra en juego la conversión explícita.
	
	A continuación, detallamos las conversiones más importantes y cómo usarlas a tu favor:
	\begin{itemize}
		\item \textbf{De \texttt{float} a \texttt{int}}: Al convertir un decimal a entero, Python simplemente ``corta'' la parte decimal, no la redondea. Por ejemplo, \texttt{int(3.9)} dará como resultado \texttt{3}. Hay que tener ojo, porque esto implica una pérdida de información.
		
		\item \textbf{De \texttt{int} a \texttt{float}}: Se añade un punto decimal vacío. Por ejemplo, \texttt{float(5)} resulta en \texttt{5.0}.
		
		\item \textbf{De \texttt{str} a numérico}: Solo funciona si el texto tiene estrictamente un formato numérico. Por ejemplo, \texttt{int("10")} es válido, pero \texttt{int("Hola")} o intentar pasar decimales directos como \texttt{int("10.5")} provocará que tu programa colapse (error).
		
		\item \textbf{De numérico a \texttt{str}}: Nos permite transformar cualquier número en texto. Esto es sumamente útil cuando queremos concatenar (unir) números con otras cadenas de texto de forma precisa.
		
		\item \textbf{Casos especiales (Booleanos)}: En Python, matemáticamente \texttt{True} equivale al número \texttt{1}, y \texttt{False} equivale al número \texttt{0}.
	\end{itemize}
	
	\subsubsection*{El peligro de \texttt{input()} y la trampa del texto}
	El casteo es particularmente crítico cuando solicitamos datos con la función \texttt{input()}. \textbf{Debes recordar siempre que \texttt{input()} retorna una variable de tipo \texttt{str} (texto)}, incluso si el usuario teclea un número por su teclado.
	
	Si intentamos sumar dos entradas de texto sin castearlas previamente, Python no las sumará matemáticamente, sino que las \textbf{concatenará} (las unirá como si fueran palabras). \\
	
	\begin{lstlisting}
		# El problema de no castear
		# Supongamos que el usuario ingresa 5000 y luego 2500
		saldo_steam = input("Ingrese su saldo de Steam: ")
		tarjeta_regalo = input("Ingrese el monto de la tarjeta de regalo: ")
		
		# Esto no dará 7500. Como son textos, Python los pega y el resultado será "50002500"
		saldo_total_erroneo = saldo_steam + tarjeta_regalo 
		
		# La solución correcta
		# Casteamos el input a int inmediatamente al recibirlo
		saldo_steam = int(input("Ingrese su saldo de Steam: "))
		tarjeta_regalo = int(input("Ingrese el monto de la tarjeta de regalo: "))
		
		# Ahora si, Python reconoce que son números y realizará una suma matemática
		saldo_total_correcto = saldo_steam + tarjeta_regalo
	\end{lstlisting}

	\subsubsection*{Pérdida de información al castear flotantes}
	Otra situación muy común es cuando necesitamos forzar un número decimal a ser un entero. Es vital recordar que \texttt{int()} simplemente trunca el número, destruyendo la precisión de los decimales.
	
	\begin{lstlisting}
		# Supongamos que monitoreamos la temperatura de una tarjeta de video (GPU)
		temp_gpu_exacta = 78.9 
		
		# Si casteamos a entero, perdemos el .9 por completo
		temp_gpu_entera = int(temp_gpu_exacta)
		
		print("Temperatura exacta:", temp_gpu_exacta) # Imprime 78.9
		print("Temperatura truncada:", temp_gpu_entera) # Imprime 78 (Perdimos casi un grado!)
	\end{lstlisting}
	
	\subsection{Librerías y funciones útiles}
	
	Por ahora, una de las funciones nativas más útiles que veremos es \texttt{round()}. A diferencia del casteo a entero que simplemente trunca los decimales, \texttt{round(numero, decimales)} redondea de manera matemática un número a la cantidad de decimales que le indiquemos. Si no le entregamos la cantidad de decimales, lo redondeará al entero más cercano.
	
	\begin{lstlisting}
		pi = 3.14159
		# Redondear a 2 decimales
		pi_redondeado = round(pi, 2)
		print(pi_redondeado) # Imprimirá 3.14
	\end{lstlisting}
	
	Sin embargo, Python tiene muchísimas herramientas matemáticas más avanzadas (como la raíz cuadrada o la trigonometría) guardadas en una ``caja de herramientas'' externa llamada \textbf{librería} (o módulo). 
	
	Para usar estas herramientas matemáticas, primero debemos decirle a nuestro programa que abra esa caja usando la instrucción \texttt{import math}. Esto idealmente debe ir en la primera línea de tu archivo de código. \\
	
	En nuestro caso, utilizaremos más que nada \texttt{sqrt(x)} para calcular la raíz cuadrada exacta de un valor \texttt{x}. De esta forma, podemos importar únicamente esa función usando directamente la instrucción \texttt{from math import sqrt}.
	
	\begin{lstlisting}
		from math import sqrt
		
		# Ejemplo: Distancia en un mapa digital (Pitágoras)
		cateto_a = 3
		cateto_b = 4
		
		# Aplicamos el teorema: c = raiz_cuadrada(a^2 + b^2)
		suma_cuadrados = (cateto_a ** 2) + (cateto_b ** 2)
		hipotenusa = sqrt(suma_cuadrados)
		
		print("La distancia es:", hipotenusa)  # Resultado: 5.0
	\end{lstlisting}
	
	\subsection{Decisiones (Control de flujo)}
	Hasta ahora, nuestros programas se ejecutan línea por línea, de arriba hacia abajo, sin saltarse nada. Sin embargo, en la programación muchas veces necesitamos tomar \textbf{decisiones}. Queremos que una parte del código se ejecute \textit{solo si} se cumple una condición específica.
	
	Para esto utilizamos la estructura \texttt{if} (si condicional), la cual sigue algunas reglas estructurales muy importantes:
	\begin{itemize}
		\item \textbf{El \texttt{if} es obligatorio e inicial:} Toda decisión arranca con un \texttt{if}. Además, un \texttt{if} puede vivir completamente solo si no necesitas revisar otros escenarios.
		\item \textbf{Puedes tener muchos \texttt{elif} (opcionales):} Si quieres evaluar múltiples condiciones distintas en cadena una tras otra, puedes agregar la cantidad de \texttt{elif} que necesites.
		\item \textbf{Solo un \texttt{else} (opcional):} Si quieres atrapar cualquier caso que no haya cumplido \textbf{ninguna} de las condiciones anteriores, usas el \texttt{else}. Solo puede haber \textbf{uno} por estructura y debe ir siempre al final.
	\end{itemize}
	
	Para evaluar estas condiciones, usamos \textbf{operadores relacionales} que comparan dos valores y siempre entregan un booleano (\texttt{True} o \texttt{False}):
	\begin{itemize}
		\item \textbf{\texttt{==}} : Igual a (Ojo! Son dos signos igual, recuerda que uno solo es para variables).
		\item \textbf{\texttt{!=}} : Distinto de.
		\item \textbf{\texttt{>}} y \textbf{\texttt{<}} : Mayor que, y Menor que.
		\item \textbf{\texttt{>=}} y \textbf{\texttt{<=}} : Mayor o igual que, y Menor o igual que.
	\end{itemize}
	
	\textbf{Regla de oro de Python:} El bloque de código que está "dentro" de una decisión se define usando \textbf{indentación} (una sangría o tabulación hacia la derecha). Todo lo que esté indentado bajo el \texttt{if} se ejecutará solo si la condición es verdadera. \\
	
	\begin{lstlisting}
		# Ejemplo 1: if y else básico
		saldo_billetera = 15000
		precio_juego = 12000
		
		# Verificamos si el saldo alcanza para el juego
		if saldo_billetera >= precio_juego:
			print("Compra exitosa. Agregado a tu biblioteca de juegos.")
			saldo_billetera = saldo_billetera - precio_juego
			print("Tu nuevo saldo es:", saldo_billetera)
		
		# Si la condición de arriba fue False, el programa salta directo aquí
		else:
			dinero_faltante = precio_juego - saldo_billetera
			print("Saldo insuficiente. Faltan", dinero_faltante, "pesos.")
		
		
		# Ejemplo 2: Múltiples decisiones con elif
		temp_cpu = 82
		
		# Solo necesitamos un if para empezar
		if temp_cpu >= 90:
			print("Peligro! Temperatura critica. Apagando equipo...")
		
		# Podemos tener tantos elif como queramos. 
		# Este se revisa SÓLO si el 'if' anterior fue falso
		elif temp_cpu >= 75:
			print("Advertencia: Procesador caliente. Revisa el ventilador y la pasta térmica.")
		
		# Solo puede haber un else, y va al final atrapando todo lo que sobró
		else:
			print("Sistema estable. Temperatura optima.")
	\end{lstlisting}
	
	\subsection{Operadores Lógicos}
	Muchas veces una sola condición no es suficiente para tomar una decisión. Qué pasa si necesitamos que se cumplan \textit{dos cosas al mismo tiempo}, o que se cumpla \textit{por lo menos una de varias}? Para esto utilizamos los operadores lógicos, los cuales nos permiten combinar o modificar múltiples condiciones:
	
	\begin{itemize}
		\item \textbf{\texttt{and}} (Y): Exige que \textbf{todas} las condiciones conectadas sean Verdaderas (\texttt{True}). Si al menos una es falsa, todo el bloque será evaluado como falso.
		
		\item \textbf{\texttt{or}} (O): Solo necesita que \textbf{al menos una} de las condiciones sea Verdadera. Será falso únicamente si todas las condiciones son absolutamente falsas.
		
		\item \textbf{\texttt{not}} (Negación): Invierte el valor lógico de una condición. Lo verdadero lo vuelve falso, y lo falso lo vuelve verdadero.
	\end{itemize}
	
	Al igual que con las matemáticas, es una excelente práctica usar \textbf{paréntesis} para separar tus condiciones lógicas. Así evitas confusiones sobre qué se está evaluando primero. \\
	
	\begin{lstlisting}
		edad = 20
		tiene_entrada = True
		dia_semana = "Viernes"
		
		# Uso de AND: Se deben cumplir AMBAS condiciones
		if (edad >= 18) and (tiene_entrada == True):
			print("Puedes ingresar al concierto.")
		else:
			print("No cumples los requisitos para entrar.")
		
		# Uso de OR: Basta con que se cumpla UNA condición
		if (dia_semana == "Sabado") or (dia_semana == "Domingo"):
			print("Es fin de semana, a descansar!")
		else:
			print("Aún es dia de semana.")
		
		# Uso de NOT: Invierte la condición
		juego_terminado = False
		
		if not juego_terminado:
			print("Sigue jugando, la partida aún no termina!")
	\end{lstlisting}

	\subsection*{Ejercicio 1: El cajero automático básico}
	
	Usted ha sido contratado para programar la lógica básica de un cajero automático. El cajero solo entrega billetes de \$10.000. 
	Escriba un programa que le pregunte al usuario cuánto dinero total tiene en su cuenta y luego le pregunte cuánto dinero desea retirar. 
	El programa debe calcular y mostrar:
	\begin{enumerate}
		\item Cuántos billetes de \$10.000 se le entregarán al usuario.
		\item Cuánto dinero quedará exactamente en su cuenta después del retiro.
	\end{enumerate}
	\textit{Nota: Asuma que el usuario siempre pide un monto que es múltiplo de 10.000 y que tiene saldo suficiente.}
	
	
	\subsection*{Ejercicio 2: Conversión de Tiempo}
	
	En astronomía, a veces los tiempos de los eventos se calculan en una cantidad gigante de segundos. 
	Escriba un programa que reciba una cantidad de segundos como número entero e imprima a cuántas horas, minutos y segundos equivale.
	\\
	\textbf{Ejemplo:} Si el usuario ingresa \texttt{3665}, el programa debe imprimir \texttt{1 horas, 1 minutos y 5 segundos}.
	
	
	\subsection*{Ejercicio 3: El promedio ponderado}
	
	En la universidad, las notas finales de un ramo se calculan con promedios ponderados. Suponga que un ramo tiene tres evaluaciones con las siguientes ponderaciones:
	\begin{itemize}
		\item Certamen 1: 30\%
		\item Certamen 2: 30\%
		\item Proyecto Final: 40\%
	\end{itemize}
	Escriba un programa que le pida al estudiante sus tres notas (que pueden tener decimales) y calcule su nota final del semestre.
	
	
	\subsection*{Ejercicio 4: El encriptador numérico}
	
	Para enviar mensajes secretos, un espía convierte cada letra en un número, formando un código largo. Para evitar ser descubierto, el espía necesita un programa que aplique un hash matemático simple a un número entero de exactamente \textbf{cuatro dígitos} (por ejemplo, \texttt{4183}). \\
	
	El algoritmo de encriptación que debes programar sigue estos pasos:
	\begin{enumerate}
		\item Extraer el primer dígito (el de los miles) y el último dígito (el de las unidades).
		\item Sumar ambos dígitos.
		\item Multiplicar esa suma por el número original completo.
		\item El resultado final es el código encriptado a imprimir.
	\end{enumerate}
	\textit{Restricción obligatoria: Está estrictamente prohibido usar \texttt{str()} para tratar el número como texto y extraer sus caracteres. Debe resolverse usando únicamente divisiones enteras (\texttt{//}) y módulo (\texttt{\%}).}
	
	
	\subsection*{Ejercicio 5: Calculadora de Envíos de Hardware}
	
	Estás comprando componentes electrónicos y el costo de envío depende del peso total del paquete (en gramos) y la distancia (en kilómetros).
	La fórmula del costo base es: $$Costo = (peso \cdot 5) + (distancia \cdot 10)$$
	
	Además, se aplican los siguientes recargos o descuentos según el costo base calculado:
	\begin{itemize}
		\item Si el costo base es estrictamente menor a \$5.000, se cobra un recargo fijo de \$1.000 por embalaje.
		\item Si el costo base está entre \$5.000 y \$10.000 (ambos inclusive), no hay recargos extra.

	Reglas del multiplicador de nivel (Diferencia = Nivel Jugador - Nivel Enemigo):

	\section{Soluciones Propuestas}

	\subsection*{Solución Ejercicio 1}
	\begin{solucion}
		Para calcular la cantidad de billetes, aprovechamos la división entera (\texttt{//}), la cual nos dice exactamente cuántas veces cabe el valor de 10.000 en el monto solicitado. Para obtener el saldo final, realizamos una simple resta.
		
		\begin{lstlisting}
			saldo_inicial = int(input("Ingrese su saldo total: "))
			monto_retiro = int(input("Ingrese monto a retirar: "))
			
			# Calculamos los billetes usando division entera
			billetes_10k = monto_retiro // 10000
			
			# Calculamos el nuevo saldo
			saldo_final = saldo_inicial - monto_retiro
			
			print("Se entregarán", billetes_10k, "billetes de $10.000")
			print("Su nuevo saldo es:", saldo_final)
		\end{lstlisting}
	\end{solucion}
	
	\subsection*{Solución Ejercicio 2}
	\begin{solucion}
		Este es un ejercicio clásico de conversión. La división entera (\texttt{//}) nos da la unidad mayor (cuántas horas o minutos completos hay), mientras que el módulo (\texttt{\%}) rescata el "sobrante" (los segundos restantes) para seguir subdividiéndolos.
		
		\begin{lstlisting}
			total_segundos = int(input("Ingrese la cantidad de segundos: "))
			
			# Una hora tiene 3600 segundos (60 * 60)
			horas = total_segundos // 3600
			
			# Nos quedamos con los segundos sobrantes despues de sacar las horas
			segundos_restantes = total_segundos % 3600
			
			# De esos sobrantes, sacamos los minutos
			minutos = segundos_restantes // 60
			
			# Lo que sobra finalmente son los segundos
			segundos_finales = segundos_restantes % 60
			
			print(horas, "horas,", minutos, "minutos y", segundos_finales, "segundos.")
		\end{lstlisting}
	\end{solucion}

	\subsection*{Solución Ejercicio 4}
	\begin{solucion}
		Al usar \texttt{// 1000}, eliminamos los últimos tres dígitos de un número de 4 cifras, quedándonos solo con el primero. Por otro lado, al aplicar módulo base 10 (\texttt{\% 10}) a cualquier número, siempre obtendremos exclusivamente su unidad.
		
		\begin{lstlisting}
			numero_original = int(input("Ingrese un número de 4 digitos: "))
			
			# Ejemplo mental con 4183:
			# Para sacar el primer digito (4), dividimos por 1000 y botamos los decimales
			primer_digito = numero_original // 1000
			
			# Para sacar el ultimo digito (3), pedimos el resto de la division por 10
			ultimo_digito = numero_original % 10
			
			# Realizamos las operaciones matematicas solicitadas
			suma_extremos = primer_digito + ultimo_digito
			codigo_encriptado = suma_extremos * numero_original
			
			print("El codigo encriptado es:", codigo_encriptado)
		\end{lstlisting}

	\subsection*{Solución Ejercicio 5}
	\begin{solucion}
		Primero, se calcula un costo base preliminar usando la fórmula entregada. Luego, utilizamos una cascada de \texttt{if / elif / else} para evaluar en qué tramo monetario cae ese costo y aplicar el recargo o descuento. Al usar \texttt{elif}, aseguramos que el programa evalúe un tramo a la vez de forma segura.
		
		\begin{lstlisting}
			peso = float(input("Ingrese el peso del paquete (g): "))
			distancia = float(input("Ingrese la distancia (km): "))
			
			# Calculamos el costo base con la formula dada
			costo_base = (peso * 5) + (distancia * 10)
			
			# Evaluamos los recargos y descuentos
			if costo_base < 5000:
				costo_final = costo_base + 1000
			elif costo_base <= 10000:
				costo_final = costo_base
			elif costo_base <= 20000:
				# Descuento del 10% significa que pagamos el 90%
				costo_final = costo_base * 0.90
			else:
				# Descuento del 20% significa que pagamos el 80%
				costo_final = costo_base * 0.80
			
			print("El costo de envio final es: $", round(costo_final))
		\end{lstlisting}
	\end{solucion}

	\subsection*{Solución Ejercicio 8}
	\begin{solucion}
		Tras calcular el daño base según la fórmula, se determina la diferencia de niveles. El bloque de validaciones está ordenado estrictamente desde el caso más negativo al positivo; el orden de los \texttt{elif} es crucial para que Python no asigne un multiplicador incorrecto antes de tiempo.
		
		\begin{lstlisting}
			ataque = float(input("Ataque del jugador: "))
			nivel_jugador = int(input("Nivel del jugador: "))
			defensa = float(input("Defensa del enemigo: "))
			nivel_enemigo = int(input("Nivel del enemigo: "))
			
			# Calculamos el daño base
			dano_base = ataque * (ataque / defensa)
			diferencia = nivel_jugador - nivel_enemigo
			
			# Determinamos el multiplicador con multiples elif
			if diferencia <= -5:
				multiplicador = 0.5
			elif diferencia < 0:
				multiplicador = 0.8
			elif diferencia == 0:
				multiplicador = 1.0
			elif diferencia < 5:
				multiplicador = 1.2
			else:
				multiplicador = 1.5
			
			dano_final = dano_base * multiplicador
			print("El daño final infligido es:", round(dano_final, 1))
		\end{lstlisting}
	\end{solucion}

	\subsection*{Solución Ejercicio 10}
	\begin{solucion}
		Calculamos las diferencias de las coordenadas y las elevamos al cuadrado de inmediato. Luego, para el último paso de Pitágoras, invocamos \texttt{math.sqrt()} desde la librería importada para resolver la raíz cuadrada.
		
		\begin{lstlisting}
			from math import sqrt
			
			# Solicitamos las 4 coordenadas
			x1 = float(input("Ingrese x1: "))
			y1 = float(input("Ingrese y1: "))
			x2 = float(input("Ingrese x2: "))
			y2 = float(input("Ingrese y2: "))
			
			# Calculamos las diferencias y las elevamos al cuadrado
			dif_x_cuadrado = (x2 - x1) ** 2
			dif_y_cuadrado = (y2 - y1) ** 2
			
			# Sumamos y aplicamos raiz cuadrada (sqrt)
			distancia = sqrt(dif_x_cuadrado + dif_y_cuadrado)
			
			# Redondeamos a 2 decimales
			distancia_final = round(distancia, 2)
			
			print("La longitud del cable debe ser de", distancia_final, "milímetros.")
		\end{lstlisting}
	\end{solucion}
