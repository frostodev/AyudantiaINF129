	\section{Variables y Tipos de Datos}
	
	\begin{frame}{¿Qué es una variable?}
		Piensa en una variable como una \textbf{caja con una etiqueta}.
		\begin{itemize}
			\item Nos permite guardar datos en la memoria del computador para usarlos, modificarlos o leerlos después.
			\item En Python, no necesitamos declarar el tipo de variable antes de usarla.
		\end{itemize}
		
		\vspace{0.5cm}
		\begin{alertblock}{El operador de asignación ($=$)}
			En programación, un solo signo igual (\texttt{=}) \textbf{no significa igualdad matemática}. Significa \textbf{asignación}: ``toma el valor de la derecha y guárdalo en la variable de la izquierda''.
		\end{alertblock}
	\end{frame}
	
	\begin{frame}{Tipos de datos fundamentales}
		Dependiendo de la información que queramos guardar en la ``caja'', Python clasifica los datos en distintos tipos:
		\begin{itemize}
			\item \textbf{Enteros (\texttt{int}):} Números sin parte decimal (ej. \texttt{42}, \texttt{-5}).
			\item \textbf{Flotantes (\texttt{float}):} Números con decimales (ej. \texttt{3.14}, \texttt{-0.5}). \textit{Ojo: en programación siempre se usa el punto, no la coma.}
			\item \textbf{Cadenas de texto (\texttt{str}):} Texto plano. Siempre debe ir entre comillas dobles o simples (ej. \texttt{"Hola"}, \texttt{'A'}).
			\item \textbf{Listas (\texttt{list}):} Una colección que nos permite guardar múltiples valores juntos en un solo lugar (ej. \texttt{[1, 2.5, "texto"]}).
		\end{itemize}
	\end{frame}
	
	\begin{frame}[fragile]{Veamos el código}
		Así se ven estos conceptos aplicados directamente en Python:
		
		\begin{lstlisting}
# Asignando distintos tipos de datos a variables
edad = 19                   # int
promedio = 85.5             # float
nombre = "UTFSM"            # str
ramos = ["Intro", "Fisica"] # list

# Podemos reasignar valores facilmente
edad = 20

# Y podemos imprimir para verificar lo que guardamos
print(nombre)
print(ramos)
\end{lstlisting}
	\end{frame}
