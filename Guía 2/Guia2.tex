	\section{Resumen de la materia}
	
	\subsection{Introducción a los ciclos (o bucles)}
	Hasta ahora, nuestros programas se han ejecutado de manera lineal: línea por línea, de arriba hacia abajo, tomando decisiones ocasionales con \texttt{if}, pero siempre avanzando hacia el final. Sin embargo, en la programación real es extremadamente común necesitar que una instrucción (o un bloque entero de código) se ejecute múltiples veces. A estas estructuras de repetición controlada las llamamos \textbf{ciclos} o \textbf{bucles}.
	
	\subsection{El ciclo \texttt{while} (Mientras)}
	El ciclo \texttt{while} nos permite repetir un bloque de código \textbf{mientras} una condición específica sea verdadera (\texttt{True}). 
	
	Puedes pensarlo como un \texttt{if} que se repite: evalúa una condición, y si es verdadera, ejecuta su código indentado. La gran diferencia es que, al terminar de ejecutar ese bloque, el \texttt{while} "vuelve arriba" y revisa la condición nuevamente. Si sigue siendo verdadera, repite el bloque una vez más, y así sucesivamente hasta que la condición se vuelva falsa.
	
	Para que un ciclo \texttt{while} funcione correctamente y no cause problemas, generalmente debe tener \textbf{tres partes fundamentales}:
	\begin{enumerate}
		\item \textbf{Inicialización:} Una variable definida \textit{antes} de comenzar el ciclo, la cual será evaluada en la condición.
		\item \textbf{Condición:} La expresión lógica (usando \texttt{>}, \texttt{<}, \texttt{==}, etc.) que determina si el ciclo entra a dar una vuelta o si se detiene.
		\item \textbf{Actualización:} Un cambio que ocurre \textit{dentro} del bloque del ciclo que modifica la variable inicial. ¡Si olvidamos este paso, la condición nunca cambiará, creando un temido \textbf{ciclo infinito} que colgará nuestro programa!
	\end{enumerate}
	
	\begin{lstlisting}
		# Ejemplo 1: Un contador simple
		contador = 1  # 1. Inicialización de la variable
		
		# 2. Condición: Mientras el contador sea menor o igual a 5
		while contador <= 5:  
		print("El contador va en:", contador)
		
		# 3. Actualización: Aumentamos en 1 el contador en cada vuelta (Fundamental)
		contador = contador + 1  
		
		# Esta línea está fuera del while (sin indentar), se ejecuta al terminar el ciclo
		print("¡El ciclo ha terminado!")
	\end{lstlisting}
	
	\subsubsection*{Uso clásico: Validación de datos}
	Una de las aplicaciones más útiles y comunes del ciclo \texttt{while} es obligar al usuario a ingresar un dato correcto antes de que el programa pueda continuar. Si el usuario se equivoca, el ciclo lo "atrapa" y le vuelve a pedir el dato \textit{mientras} su respuesta siga siendo incorrecta o inválida.
	
	\begin{lstlisting}
		# Ejemplo 2: Validación de una contraseña
		print("Bienvenido al sistema secreto.")
		
		# Inicialización: Pedimos la contraseña por primera vez
		contrasena = input("Ingrese la contraseña: ")
		
		# Condición: Mientras la contraseña NO sea "1234", el acceso es denegado
		while contrasena != "1234":
		print("Error: Contraseña incorrecta. Intente nuevamente.")
		
		# Actualización: Volvemos a pedir la contraseña para que el usuario tenga otra oportunidad
		contrasena = input("Ingrese la contraseña: ") 
		
		# Si llegamos a esta línea, significa que el while terminó (la contraseña fue correcta)
		print("¡Acceso concedido! Sistema desbloqueado.")
	\end{lstlisting}
